코드가 연결되지 않아요.

코드는 발급 후 10분간 유효합니다. {{SUPPORT_NAME}}에게 새 코드를 요청해 다시 입력하세요. 프로그램 실행 뒤 연결이 끊겼다면 새 코드가 필요합니다.

원격지원을 멈추고 싶어요.

프로그램의 ‘즉시 종료’를 누르세요. 프로그램 하단에 표시된 종료 단축키도 사용할 수 있습니다. 단축키를 사용할 수 없는 경우 프로그램에 안내가 표시됩니다.

파일을 실행할 수 없어요.

Windows 7 SP1·8.1·10·11과 .NET Framework 4.8 이상이 필요합니다. Windows 7 SP1 호환은 실제 PC에서 확인 중입니다. XP·Vista·Windows 8.0·휴대폰은 지원하지 않습니다. Windows 7은 Windows 업데이트와 루트 인증서 상태도 확인해야 합니다. Windows가 게시자를 확인하지 못하거나 조직의 보안 정책이 실행을 막으면 표시된 내용을 {{SUPPORT_NAME}}에게 전달하세요.

.NET Framework가 필요하다고 나와요.

Microsoft 공식 .NET Framework 4.8 런타임 다운로드에서 설치한 뒤 PC를 다시 시작하세요. Windows 7은 SP1이 필요하며 4.8.1은 설치할 수 없습니다. 설치가 막히면 PC 관리 담당자에게 문의하세요. 호환 업데이트가 모든 PC에서의 실행을 보장하지는 않습니다.

Chrome에서 의심스러운 다운로드로 차단됐어요.

다운로드를 중단하고 표시된 경고를 {{SUPPORT_NAME}}에게 알려주세요. 브라우저 보호 기능을 끄거나 차단을 무시하지 마세요. 담당자는 실제 배포 파일을 점검하고, 필요한 경우 Google의 공식 검토 절차로 확인해야 합니다. v0.10도 경고가 사라지는 것을 보장하지 않습니다.
